# ALU Simple de 2 bits

Este repositorio contiene la simulación en Wokwi de una Unidad Aritmético Lógica (ALU) combinacional para la Tarea 4 de Hardware Digital (ISF-215).

El módulo realiza cuatro operaciones (AND, OR, XOR y SUMA) sobre operandos de entrada, controladas por dos bits de selección (S1, S0). El diseño se basó en una celda de 1 bit simplificada mediante álgebra de Boole, la cual fue instanciada en paralelo para procesar 2 bits.
